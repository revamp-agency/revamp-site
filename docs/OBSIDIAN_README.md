# REVAMP

The project folder for building the Revamp agency website.

## Structure

- `00_planning/` — all thinking, content, references, decisions
- `01_assets/` — logo, fonts, images, icons
- `02_legal/` — privacy, cookie, terms (drafted in Phase 2)
- `03_code/` — the Next.js project (created in Phase 3)
- `04_launch/` — SEO checklist, analytics setup, post-launch notes
